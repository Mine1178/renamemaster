第一章 软件简介

1.1 产品定位

RenameMaster 是一款完全在本机运行的 Windows 桌面端「文件批量命名助手」，面向通信勘察、工程台账、日常办公等场景，解决照片、表格、文档批量改名 以及照片压缩到指定大小的问题。软件不联网、不上传、不收集任何数据，所有处理均在本机完成，可断网使用。

命名前先在预览表中列出「原文件名 → 新文件名 / 原大小 → 预计新大小 / 状态」，确认无误后才真正写盘；输出结果一律写入独立目录，源文件零改动。

第二章 安装与启动

2.1 免安装版（推荐）

1. 把 RenameMaster.exe 复制到任意目录（建议 D:\Tools\RenameMaster\）。

2. 双击 RenameMaster.exe 即可启动，无需安装、无需管理员权限。

3. 首次启动若被 Windows SmartScreen 拦截，点「更多信息」→「仍要运行」即可。本软件未做代码签名，属正常现象。

若杀毒软件提示风险，亦为 PyInstaller 打包的单文件 EXE 常见误报，加入信任列表即可。

2.2 源码方式运行

需要在本地修改或二次开发时，可用源码方式启动：

cd D:\Desktop\SD\13.Rename\src

pip install -r ..\requirements.txt

python -m rename_master.main

python ..\tests\smoke.py :: 输出 SMOKE OK 即通过

2.4 配置文件与日志

· 配置文件：%APPDATA%\RenameMaster\config.json，保存最近使用的目录、上次选择的压缩档位、水印文字等；删除该文件即可恢复默认设置。

· 运行日志：logs\rename_YYYYMMDD.log，按天记录每次执行的文件与结果。

第三章 快速上手

3.1 五步跑通照片批量改名

1. 启动软件，在左侧导航点「照片命名」。

2. ① 选择文件：点「📂 选择文件夹」指定源目录，或点「➕ 添加文件」多选照片；也可直接从资源管理器把文件夹拖入窗口。

3. ② 命名模式：选「模式一：统一前缀+序号」，填写「基础名称」（如 曲靖巡检），按需调整位数、起始、分隔符，并勾选「保留扩展名」。

4. ③ 压缩到指定大小：选 500 KB（或 1 MB / 200 KB / 100 KB / 自定义）；如需水印，在 ④ 卡片勾选「添加水印文字」并填写文字、位置、字号。

5. ⑤ 输出位置：确认默认输出目录后，点底部「▶ 开始执行」，在弹出的预览表中核对无误，再点「▶ 确认执行」。

执行过程中可随时点「✖ 取消」中断；完成后弹窗提示成功与失败数量，并给出输出目录路径。

第四章 功能详解

4.1 照片批量命名

支持格式：jpg / jpeg / png / bmp / heic。页面由「① 选择文件、② 命名模式、③ 压缩到指定大小、④ 水印（可选）、⑤ 输出位置」五张卡片组成。

4.1.1 模式一：统一前缀 + 序号

适用于把一堆乱名照片（IMG_20260101.jpg、DSC_001.jpg …）统一改成「曲靖巡检_001.jpg、曲靖巡检_002.jpg …」。参数说明如表 5 所示。

表 5 模式一参数说明

示例：基础名称 = 曲靖巡检、位数 = 3、起始 = 1、分隔符 = _，则输出为 曲靖巡检_001.jpg、曲靖巡检_002.jpg …，序号按文件列表顺序递增。

4.1.2 模式二：Excel 对照表一一对应

1. ① 选择文件：指定照片源目录。

2. ② 命名模式：选「模式二：一一对照（Excel）」。

3. 点「📥 从 Excel 导入」选择对照表文件（.xlsx / .xls / .csv）。

4. 在卡片内的对照表中核对「原文件名 → 新文件名」，确认无误后点「👁 预览改名结果」。

5. 在预览弹窗点「▶ 确认执行」。

对照表规则：第 1 列为原文件名、第 2 列为新文件名；未匹配到的文件保持原名；解析失败会弹出错误提示，不会误改任何文件。

4.1.3 压缩到指定大小

各档位与适用场景如表 6 所示。

表 6 压缩档位与适用场景

压缩原理：用二分法调整 JPEG quality（1~95），压不到目标大小再等比缩小分辨率，保证最终文件不大于目标大小。勾选「保留 EXIF」可在压缩后保留拍摄参数等信息。

4.1.4 照片水印（v1.0 新增）

水印卡片默认关闭，勾选「添加水印文字」后启用；启用后会在压缩完成之后为每张照片叠加半透明白色文字，适合给现场照片标注地点、日期或班组。参数说明如表 7 所示。

表 7 水印参数说明

· 水印为白色半透明文字（不透明度 40%），距图片边缘的距离等于字号，字号随图片短边自适应，不同尺寸照片观感一致。

· 执行顺序为「先压缩、后加水印」，避免水印被二次压缩糊掉；未开启压缩时也可单独加水印。

· 水印文字为空或仅空白时，原样输出，不加水印。

· 全程在内存中完成，不落盘、不改动原图；输出统一为 JPEG（quality=95）。

· 若透明图（PNG）参与处理，会先合成到白底，避免转 JPEG 后透明区变黑。

4.1.5 预览确认与执行

点「▶ 开始执行」后会先弹出预览表，列出「原文件名 / 新文件名 / 原大小 / 预计新大小 / 状态」。状态含义如表 8 所示。

表 8 预览状态说明

预览表中文件名若含 \ / : * ? " < > | 等非法字符，程序会自动替换为下划线 _，并在预览表中标黄提示。

4.2 表格批量命名

适用于把一批表格文件（.xlsx / .xls / .csv）按规则批量改名，例如把「新建 XLS 工作表.xlsx」改成「台账_001.xlsx」。

1. 左侧导航点「表格命名」，在 ① 选择文件 中指定源目录或添加文件。

2. 在 ② 命名规则 中选择「统一前缀 + 序号」，可设置位数 / 起始号 / 分隔符。

3. 在 ③ 输出位置 中确认输出目录。

4. 点底部「👁 预览改名结果」核对，再点「▶ 开始执行」并确认。

表格页不做压缩与水印处理，仅执行改名，源文件保持零改动。

4.3 文档批量命名

适用于把一堆无意义命名的 Word / PDF / TXT / Markdown 文档，按内容自动命名。支持格式：.docx / .pdf / .txt / .md。

· 命名规则为「前缀 + 正文开头 + 序号」，三项可自由叠加，按需勾选。

· 正文提取规则：.docx 取正文前 30 个字符，.pdf 取第 1 页前 30 个字符，.txt / .md 取前 30 个字符。

· 提取到的正文会自动去除换行、多余空格与文件名非法字符。

· 可在前缀框中填写固定前缀，如「巡检报告_」。

表 9 文档命名规则示例

PDF 正文提取依赖 pypdf；若 PDF 为扫描件（无文字层），提取结果可能为空，此时会保留原文件名并在预览表中标注。

4.4 首页与关于页

· 首页：三张功能卡片（照片命名 / 表格命名 / 文档命名），点击直接进入对应功能页；下方「最近使用」记录最近处理的目录。

第六章 数据与隐私

· 纯本地运行：不联网、不上传、不收集任何数据，可断网使用。

· 所有文件处理都在本机内存与磁盘完成，无任何外部通信。

· 原文件零改动：输出统一写入「<源目录>_重命名输出」，绝不原地覆盖。

· 本机配置：仅 %APPDATA%\RenameMaster\config.json 一处，记录目录与选项偏好，删除即恢复默认。

· 运行日志：仅记录文件名与处理结果，不含文件内容。

问题 原因 解决办法
原文件会被覆盖吗？ 程序采用输出目录隔离设计 不会。所有输出写到新目录，原文件零改动。
文件名里有非法字符（\ / : * ? " < > |）怎么办？ Windows 文件名不允许这些字符 自动替换为下划线 _，预览表中标黄提示。
压缩后图片会模糊吗？ 二分法优先调整 JPEG 质量 先调质量（肉眼几乎无差），压不到才等比缩分辨率。
支持哪些图片格式？ 扫描器按扩展名白名单过滤 jpg / jpeg / png / bmp / heic。
压缩档位怎么选？ 不同渠道的大小限制不同 微信发图选 200 KB，邮件附件选 500 KB，存档选 1 MB。
加了水印想去掉怎么办？ 水印已直接写入输出图片 取消勾选「添加水印文字」后重新执行一次；原图始终未改动。
水印太淡或太大看不清？ 字号按图片短边比例自适应 把「字号」调为「大」，或换到对比度更高的位置。
杀毒软件报毒？ 程序未做代码签名 PyInstaller 打包的 EXE 偶被误报，加入信任即可。
配置存在哪里？如何恢复默认？ 配置写在系统应用数据目录 %APPDATA%\RenameMaster\config.json，删除即恢复默认。
执行中途想停止？ 后台线程支持取消 点底部「✖ 取消」；已写入的文件保留，未处理的不再继续。
想查看历史执行记录？ 日志按天写入 查看 logs\rename_YYYYMMDD.log。

第一章 软件简介

1.1 产品定位

RenameMaster 是一款完全在本机运行的 Windows 桌面端「文件批量命名助手」，面向通信勘察、工程台账、日常办公等场景，解决照片、PDF、表格、文档批量改名、照片压缩到指定大小的问题。软件不联网、不上传、不收集数据，所有处理均在本机完成，可断网使用。

命名前先在预览表中列出「原文件名 → 新文件名 / 原大小 → 预计新大小 / 状态」，确认无误后才真正写盘；输出结果一律写入独立目录，源文件零改动。

第二章 安装与启动

2.1 安装包方式（推荐）

1. 双击 RenameMaster_Setup.exe，按向导安装，可勾选「创建桌面快捷方式」。

2. 从开始菜单或桌面双击 RenameMaster 启动。

3. 卸载：设置 → 应用 → RenameMaster → 卸载，会一并清理 %APPDATA%\RenameMaster。

2.2 免安装版

1. 把 RenameMaster.exe 复制到任意目录，双击即可启动。

2. 首次若被 SmartScreen 拦截，点「更多信息」→「仍要运行」（未做代码签名，属正常）。

3. 杀毒软件若提示风险，为 PyInstaller 单文件 EXE 常见误报，加入信任即可。

2.3 源码方式运行

需要二次开发时，可用源码方式启动：

cd D:\Desktop\SD\13.Rename\src

pip install -r ..\requirements.txt

python -m rename_master.main

python ..\tests\smoke.py :: 输出 SMOKE OK 即通过

第三章 快速上手

3.1 五步跑通照片批量改名

1. 左侧导航点「照片命名」。

2. ① 选择文件：点「选择文件夹」或「添加文件」，也可直接拖入文件夹。

3. ② 命名模式：选模式一，填基础名称（如 曲靖巡检），调整位数、起始、分隔符。

4. ③ 压缩档位：选 500 KB（或 1M / 200K / 100K / 自定义）。

5. ④ 输出位置：点「开始执行」，预览表核对无误后确认执行。

执行过程中可随时点「取消」中断；完成后弹窗提示成功与失败数量。

4.1 照片批量命名

支持格式：jpg / jpeg / png / bmp / webp / tiff。

4.1.1 模式一：统一前缀 + 序号

4.1.2 模式二：Excel 对照表

1. 选模式二后，点「一键提取文件名」导出当前文件清单为 Excel 模板。

2. 在模板「新文件名」列填好新名，再点「导入对照表」。

3. 也可直接导入现成 Excel / CSV，或导出当前对照表。

4. 重名 / 未匹配行自动标色，确认后预览执行。

重复判定基于最终完整文件名：新名不带扩展名也不会误判；真正重复的行会被标红禁止。

4.2 PDF 批量命名

· 模式一：统一前缀 + 序号；勾选「提取正文开头」可按第 1 页内容命名。

· 模式二：Excel 对照表，支持一键提取文件名、导入、导出。

4.3 表格批量命名

· 支持 .xlsx / .xls / .csv，模式一 / 模式二操作同照片页。

· 仅改名，不做压缩、不改动内容。

4.4 文档批量命名

· 支持 .docx / .pdf / .txt，提取正文开头作为新文件名，可配字数。

· 可叠加固定前缀 + 序号；扫描件（无文字层）会保留原名并标注。

4.5 高级选项（折叠，默认收起）

· 命名变量：{date} 今天、{mtime} 修改时间、{exif} 拍摄时间、{parent} 父文件夹、{stem} 原名。

· 自定义排序：按文件名 / 大小 / 修改时间，升序 / 降序，决定序号顺序。

· 查找替换：普通文本或正则批量替换，非法正则安全降级。

4.6 撤销

每次执行记录产物，可点「撤销上次操作」（跨重启），删除生成物并清理空目录。

4.7 文字复制

界面标题、说明、标签、表格表头均可鼠标拖选，Ctrl+C 复制或右键复制；只读文字采用白名单，不会被键盘误删、粘贴或修改。

第六章 数据与隐私

· 纯本地运行：不联网、不上传、不收集任何数据，可断网使用。

· 所有文件处理都在本机内存与磁盘完成，无任何外部通信。

· 原文件零改动：输出统一写入「<源目录>_重命名输出」，绝不原地覆盖。

· 本机配置：仅 %APPDATA%\RenameMaster\config.json 一处，记录目录与选项偏好，删除即恢复默认。

· 运行日志：仅记录文件名与处理结果，不含文件内容。

开源批量重命名工具 · 功能调研与借鉴建议
对照 GitHub 上 6 个主流开源项目，梳理 RenameMaster 已具备 / 缺失的能力，并给出可落地的优先级。调研日期 2026-10-13。
一、主流开源工具一览
F2
Go · MIT · 跨平台
功能最全的 CLI 标杆，变量/正则/撤销/冲突处理极完整。
PBRenamer
Python+Qt6 · GPLv3 · 跨平台
与本项目技术栈最接近，GUI+CLI，最值得直接参考。
Szyszka
Rust+GTK3 · MIT · 跨平台
多规则自由组合、可重排序，快，能处理数十万条。
Ant Renamer
Delphi · GPL · Windows
经典老牌，支持 EXIF、随机名、扩展名替换。
Métamorphose
Python+wx · GPL · 跨平台
规则化程度高，文件夹也可批量改名。
PowerRename
C# · MIT · Windows（PowerToys）
微软官方，搜索替换 + 正则 + 预览，简洁。

三、借鉴优先级建议
第一梯队 · 高价值，建议优先做
① 撤销 Undo
所有工具的标配安全兜底。记录改名前后映射即可，你已有对照表基础，成本低。
② 查找替换（含正则）
清理文件名里的杂乱字符、空格、编号，最高频；正则可做删除/交换。
③ 排序选项
决定序号顺序：按文件名/修改时间/拍摄时间。现场照片按时间编号是刚需。
④ 日期 / EXIF 变量
照片按拍摄日期、文件按修改时间命名，父目录名也可作变量。
第二梯队 · 实用，成本低
⑤ 大小写 / 空格 / 分隔符统一转换  ·  ⑥ 父目录名变量  ·  ⑦ 仅对勾选的行应用改名  ·  ⑧ 常用规则保存为预设（Preset）
第三梯队 · 扩展，按需再做
⑨ 递归子目录 + 文件过滤  ·  ⑩ 多规则组合（需调整架构，成本较高） ·  ⑪ 文件夹重命名  ·  ⑫ 随机名 / 文件哈希 / ID3 音乐标签 / 命令行（与当前场景关系较小）
一句话结论： 核心的"前缀+序号 / 对照表 / 压缩 / 正文提取"你已经有了，最划算的补强是 撤销 + 查找替换/正则 + 排序 + 拍摄日期变量——这四项正好覆盖现场照片、文档整理最容易出错和返工的环节；PBRenamer 是最适合直接参考的开源实现。
